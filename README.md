# ShikhaGhor — SSC Coaching Center

A responsive landing page for **ShikhaGhor**, an SSC coaching center website designed for Class 9–10 students in Bangladesh.

## 📌 About the Project

ShikhaGhor provides information about SSC coaching programs, free learning resources, instructors, tuition fees, and enrollment.

The website features a clean, modern design with Bengali and English content.

## ✨ Features

* 📱 Responsive design for mobile, tablet, and desktop
* 🏠 Modern landing page
* 📚 Free classes section with embedded YouTube lessons
* 👨‍🏫 Instructor information
* 💰 Subject-wise tuition fees
* 📞 Contact and enrollment section
* 📱 Mobile navigation menu
* 🎨 Smooth animations and hover effects
* 🇧🇩 Bengali & English content

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* YouTube Embed

All HTML, CSS, and JavaScript are currently contained in a single `index.html` file.


## 📚 Project Type

This project was developed as a **Programming Hero course assignment** to practice frontend web development and responsive UI design.
